# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `cuid2gen`, do not open a public
GitHub issue.

Instead, report it privately to:

- ping@raikusy.dev

Please include:

- A description of the issue
- Steps to reproduce or a proof of concept
- The affected version or commit if known
- Any suggested remediation or relevant context

You will receive an acknowledgment as soon as practical. After the report is
reviewed, the maintainer will coordinate remediation and disclosure timing.

## Supported Versions

This project does not currently publish a formal long-term support policy.
Security fixes are applied to the latest maintained code on a best-effort basis.
